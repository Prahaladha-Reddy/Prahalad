# Prahalad AI portfolio

A full-black personal portfolio for an AI engineer. Built with Vite, React, Phosphor icons, custom CSS, and a generated technical hero asset.

The visual direction is an AI systems failure atlas: black canvas, hard off-white type, burnt-orange signal marks, muted inspection colors, tight micro-matrices, trace lanes, case-file language, and compact instrument-panel motion. No neon, glassmorphism, coffee-shop lifestyle imagery, AI orbs, fake dashboards, or decorative gradients.

## Run locally

```powershell
npm install t
npm run dev
```

Then open the local URL printed by Vite.

## Edit content

Most page copy lives in `src/main.jsx`. The visual system and responsive layout live in `src/styles.css`. Replace `mailto:hello@example.com` with your real email before publishing.
